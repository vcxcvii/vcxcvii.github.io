{% comment %} The page light. One button that cycles the three grounds, light to beige to dark and back, showing which one is on: an empty disc, a half disc, a filled disc. assets/js/theme.js writes the markup. Without JavaScript nothing renders at all, because a control that cannot do anything should not occupy a tap target; the reader's system setting still decides the ground in that case, exactly as it did before this existed. It sits at the right pole of the masthead past contact, which is what makes it reachable at any scroll depth. Below 44rem it moves into the dropdown with the links, which is the gutter a 320px screen does not have. {% endcomment %}
