days since this site went live, on 17 May 2026. Borrowed from days.ramp.com, which counts the days since Ramp was founded so nobody forgets that tomorrow is already too late. Here is why I built mine.

Every week since the site went live appears below, whether or not anything happened in it. Each one can carry a stated intention, and under it the things that landed, dated. Essays and side-quest releases add themselves, because they are already published and dated elsewhere on this site. Everything else I write down by hand. Finished work is struck through, work I did not finish stays open after the week ends, and work I killed says so.

{% comment %} Every week from the launch week to the current one is generated here rather than listed in _data/days.yml. A week only visible because it was typed out is not a record: the weeks I did nothing in are exactly the ones that would go missing. The data file supplies intentions and hand-written items; the weeks themselves are arithmetic. Week boundaries are Monday. 17 May 2026 was a Sunday, so the launch week starts Monday 11 May 2026. {% endcomment %} {% assign today_date = site.time | date: "%Y-%m-%d" %} {% assign seen_releases = "" %} {% assign week_seconds = 604800 %} {% assign first_monday = "2026-05-11" | date: "%s" | plus: 0 %} {% assign weekday = site.time | date: "%u" | plus: 0 %} {% assign into_week = weekday | minus: 1 | times: 86400 %} {% assign current_monday = today_seconds | minus: into_week %} {% assign week_index_max = current_monday | minus: first_monday | divided_by: week_seconds %} {% for step in (0..week_index_max) %} {% assign week_start = week_index_max | minus: step | times: week_seconds | plus: first_monday %} {% assign week_key = week_start | date: "%Y-%m-%d" %} {% assign week_data = site.data.days | where: "week_of", week_key | first %}
